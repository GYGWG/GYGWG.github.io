# Yaowei Guo’s academic homepage

The site is built with GitHub Pages’ Jekyll renderer. Its layout and vendored stylesheets are adapted from [al-folio](https://github.com/alshedivat/al-folio). The compiled theme assets come from upstream revision `987540f5a0fba5207f01f59e85dff02a856a3743`. Local adjustments are in `assets/css/site.css`.

Edit `_data/publications.json` for papers and `_news/` for announcements. Undated notices are pinned by importance. Dated news is sorted by `event_date`, with the latest five shown initially. Use a quoted ISO day or month to match the precision of the source. The academic CV is in `cv/index.html`. The project collection is retained for future use.
