# Yaowei Guo’s academic homepage

The site is built with GitHub Pages’ Jekyll renderer. Its layout and vendored stylesheets are adapted from [al-folio](https://github.com/alshedivat/al-folio). The compiled theme assets come from upstream revision `987540f5a0fba5207f01f59e85dff02a856a3743`. Local adjustments are in `assets/css/site.css`.

Edit `_data/publications.json` for papers and `_news/` for announcements. News items with `kind: notice` are pinned by importance. Items with `kind: paper` are sorted by `event_date`, with the latest five shown initially. The academic CV is in `cv/index.html`. The project collection is retained for future use.
